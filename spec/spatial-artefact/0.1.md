# Spatial Artefact 0.1

**Status:** draft normative specification. This document is intended for publication under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Code in this repository is Apache-2.0.

## Envelope

A Spatial Artefact V0 is a directory containing `artifact.json` and a GLB payload. `artifact.json` has `artifact: "spatial"`, a `0.1.x` `specVersion`, `metadata`, a relative `model/gltf-binary` payload, and `regions`.

`payload.integrity` MAY contain `{ "algorithm": "sha256", "hash": "…" }`, where `hash` is SHA-256 over exact GLB bytes. Consumers MUST reject a mismatch and SHOULD accept a manifest without integrity for backward compatibility.

```json
{
  "artifact": "spatial",
  "specVersion": "0.1.0",
  "metadata": { "id": "hammer-001", "title": "Hammer" },
  "payload": { "type": "model/gltf-binary", "src": "./model.glb" },
  "regions": [
    {
      "id": "handle",
      "label": "Handle",
      "tags": ["wood", "grip"],
      "selector": { "type": "triangles", "mesh": "Mesh_0", "faces": [42, 43, 44] }
    }
  ]
}
```

## Selectors

V0 implementations MUST support `node`, `primitive`, and `triangles`; only the latter is authored by the V0 Mapper. `node` identifies a glTF node by name. `primitive` identifies a named mesh and primitive index. `triangles` identifies a named mesh and zero-based triangle indices. Future `attribute`, `mask`, `hotspot`, and `volume` selector kinds are reserved but are not V0.

## Stability

Triangle indices bind to the final payload. The required pipeline is **RAW → Forge → cleanup → optimization → FINAL GLB → Spatial Mapping Studio → Spatial Artefact**. No operation which changes topology or triangle order may run after V0 mapping. Producers SHOULD set `metadata.triangleMapping.finalGlb` to `true`; consumers SHOULD warn when it is absent. Future selector versions may provide more robust anchors.

The manifest is declarative data, carries no executable JavaScript, no renderer identifiers, and no Electronic Artefacts URL requirement.
